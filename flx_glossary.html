Glossary

Floating-point arithmetic

Unit roundoff

The largest relative error a single correctly rounded floating-point operation can make, written \(u\). It is \(2^{-24}\) for float and \(2^{-53}\) for double, and it sets the number of digits any result can hold.

Cancellation

The loss of significant digits when two nearby values are subtracted. The difference is computed exactly, and the digits the two operands had in common disappear from it, so the error they already carried becomes the leading part of the result. It limits a difference quotient as \(h\) shrinks.

Truncation error

The part of a formula that is dropped. A forward difference omits a term of order \(h\), which is its truncation error, and it shrinks with \(h\) while the cancellation grows.

Algebra

Unit

A symbol \(\varepsilon_i\) adjoined to the reals with \(\varepsilon_i \neq 0\) and \(\varepsilon_i^2 = 0\), called the dual unit in the literature, defined in Dual numbers. An element of order \(n\) carries \(n\) of them, and each of its components is indexed by the set of units that component carries. The unit roundoff of Floating-point arithmetic is an unrelated term.

Nilpotent

An element some power of which is zero. The units of Hyperdual Algebra satisfy \(\varepsilon_i^2 = 0\), and any element with no real part satisfies \(N^{n+1} = 0\) at order \(n\).

Order

In FLUXION, the number of nilpotent units an element carries, written Ord in the types. An element of order \(n\) holds \(2^n\) components and derivatives up to the \(n\)-th.

SIMD registers

Width

EVE's term for the number of lanes of a SIMD register, read by eve::width_v. It counts the points evaluated together, while the order counts the derivatives one point carries.

Structure of arrays

A layout storing one array per field rather than one record per element. eve::wide of a hyperdual holds one register per component, so an operation on a component is one SIMD instruction.

Automatic differentiation

Seeding

Assigning nilpotent units to an argument, so that the derivatives with respect to it are indexed by those units. Griewank and Walther's term for the same operation in forward mode. In FLUXION it is flx::variable, flx::variables, and the flx::var constructor (see Differentiation list).

Forward mode

Automatic differentiation carrying the derivatives alongside the value, in the sequence the program computes. One pass returns the value and the derivatives with respect to the seeded arguments.

Reverse mode

Automatic differentiation recording the operations of an evaluation, then traversing the record backward to accumulate derivatives. One forward pass, which stores the record, and one backward pass return the gradient with respect to every input.
