The algebra of \doxylink{flx_algebra}{Hyperdual Algebra} returns every derivative of an evaluation at once. Which argument each of them differentiates is decided when the arguments are seeded.\hypertarget{flx_seeding_flx_assignment}{}\doxysubsubsection{\texorpdfstring{Assigning units to arguments}{Assigning units to arguments}}\label{flx_seeding_flx_assignment}
Seeding a value is adding units to it. The argument a unit is given to is written in the call, and two forms write it. {\ttfamily \doxylink{group__types_ga487d2e600f4745c7eae18474d9641300_ga487d2e600f4745c7eae18474d9641300}{flx::\+variable}\texorpdfstring{$<$}{<}Ord\texorpdfstring{$>$}{>}} gives every unit of the order to a single value, and {\ttfamily \doxylink{group__types_gad882c0e62192532ad693d74ebdeb394d_gad882c0e62192532ad693d74ebdeb394d}{flx::\+variables}\texorpdfstring{$<$}{<}Is...\texorpdfstring{$>$}{>}} spreads the units of a call over its arguments:\+

The template list {\ttfamily Is...} holds one entry per unit, in unit order:\+ its $i$-\/th entry is the index of the argument $\varepsilon_i$ is given to, arguments being counted from zero and units from one. Its length is the order every seeded result comes back at. The third call above gives units 1 and 2 to the first argument and unit 3 to the second, hence an order 3 on both.

An argument that is given no unit comes back unchanged, at its own type, so the result of a call to {\ttfamily \doxylink{group__types_gad882c0e62192532ad693d74ebdeb394d_gad882c0e62192532ad693d74ebdeb394d}{flx::\+variables}} feeds the function straight through {\ttfamily kumi::\+apply}.\hypertarget{flx_seeding_flx_taylor}{}\doxysubsubsection{\texorpdfstring{Taylor identity}{Taylor identity}}\label{flx_seeding_flx_taylor}
Substituting a nilpotent into an analytic function turns its series into a sum with finitely many terms, since every monomial of degree $n+1$ in the units vanishes. That truncation is an identity, and no approximation.

For a function $f$ of $m$ arguments, seed argument $j$ with the units of a set $U_j$, the sets $U_1, \dots, U_m$ partitioning $\{1,\dots,n\}$:\+

\[ x_j = a_j + \sum_{i \in U_j} \varepsilon_i. \]

Each unit then belongs to exactly one argument, and $k$ denotes the map reading that assignment back, $k(i) = j$ for the single $j$ with $i \in U_j$. It is the list {\ttfamily Is...} of the previous section. The evaluation gives

\[ f(x_1,\dots,x_m) = \sum_{S \subseteq \{1,\dots,n\}}
    \left(\frac{\partial^{|S|} f}{\prod_{i \in S} \partial x_{k(i)}}(a_1,\dots,a_m)\right)
    \varepsilon_S. \]

Every component of the result is a partial derivative of $f$ at the point, and it carries no factorial:\+ each unit appears to the first power, so the coefficient of $\varepsilon_S$ is the derivative itself.\hypertarget{flx_seeding_flx_landing}{}\doxysubsubsection{\texorpdfstring{Reading a result}{Reading a result}}\label{flx_seeding_flx_landing}
A component is indexed by the units it carries, as \doxysectlink{flx_algebra_flx_components}{Component indexing}{1} states. One evaluation returns the gradient and the mixed second derivative. Absent from it is $\partial^2 f/\partial x^2$:\+ a second derivative in one argument needs two units on that argument, which {\ttfamily \doxylink{group__types_gad882c0e62192532ad693d74ebdeb394d_gad882c0e62192532ad693d74ebdeb394d}{flx::\+variables}\texorpdfstring{$<$}{<}0, 0\texorpdfstring{$>$}{>}} asks for.

Several components hold the same derivative, $\varepsilon_2\varepsilon_3$ answering $\partial^2 f/\partial x\,\partial y$ as $\varepsilon_1\varepsilon_3$ does. A symmetric object stored as a full set of subsets repeats itself, and that repetition is what caps the useful order at four.\hypertarget{flx_seeding_flx_cost}{}\doxysubsubsection{\texorpdfstring{Cost of an order}{Cost of an order}}\label{flx_seeding_flx_cost}
An order $n$ carries $2^n$ components, so a single value of order 4 weighs sixteen {\ttfamily double}, and every operation of the arithmetic works on all of them. Two ways of spending that budget answer different questions.


\begin{DoxyItemize}
\item {\bfseries{One unit per argument.}} Order $m$ over $m$ arguments returns the gradient and every mixed partial up to the one of order $m$, in one evaluation, and never a repeated derivative.
\item {\bfseries{Several units per argument.}} Order $n$ over one argument returns $f\textnormal{\textquotesingle}, f\textnormal{\textquotesingle}\textnormal{\textquotesingle}, \dots, f^{(n)}$ of that argument in one evaluation, and says nothing of the others.
\end{DoxyItemize}

A full Hessian of $m$ arguments therefore comes out of one pass only when $2m \le 4$. Past two arguments it is a sweep of $m(m+1)/2$ evaluations at order 2, one per pair, which is the usual shape of a forward mode.\hypertarget{flx_seeding_flx_mixing}{}\doxysubsubsection{\texorpdfstring{Mixed orders}{Mixed orders}}\label{flx_seeding_flx_mixing}
An operand of order 2 carries nothing of a third derivative, and filling it with zeros would state that the third derivative vanishes. A mixed expression therefore computes at the {\bfseries{smallest}} order present, and the extra components of the others are dropped. {\ttfamily flx::\+restrict\+\_\+to\texorpdfstring{$<$}{<}Ord\texorpdfstring{$>$}{>}} performs that descent explicitly, on the scalar form as on the wide one.

Only a lone scalar adapts to what it is mixed with. Everything that carries a structure states its own element type, and two operands stating different ones have no common type at all, which is a refusal rather than an arbitration.\hypertarget{flx_seeding_flx_wide}{}\doxysubsubsection{\texorpdfstring{Several points at once}{Several points at once}}\label{flx_seeding_flx_wide}
A component may be a SIMD register rather than a scalar, and the construction goes through unchanged. {\ttfamily eve::\+wide\texorpdfstring{$<$}{<}\doxylink{structflx_1_1hyperdual}{flx::\+hyperdual}\texorpdfstring{$<$}{<}double,2\texorpdfstring{$>$}{>}\texorpdfstring{$>$}{>}} is a structure of arrays holding as many hyperduals as the machine has lanes, and seeding a wide value seeds every lane, so one evaluation returns the derivatives at as many points as there are lanes.

This is a different axis from the order. The order says how many derivatives one point carries, the cardinal how many points travel together, and each is read where it is written:\+ the order from the element type, the cardinal from {\ttfamily eve::\+cardinal\+\_\+v}. Two operands that are genuinely wide have to agree on their number of lanes.
