\doxysubsection{Hyperdual Algebra }
\hypertarget{flx_algebra}{}\label{flx_algebra}\index{Hyperdual Algebra@{Hyperdual Algebra}}
\label{flx_algebra_md__2____w_2fluxion_2fluxion_2doc_2algebra}%
\Hypertarget{flx_algebra_md__2____w_2fluxion_2fluxion_2doc_2algebra}%


\doxylink{flx_methods}{Obtaining a Derivative} ends on forward mode, which needs a place to keep a value together with the derivatives asked of it, and an arithmetic that updates both at every operation. A number carrying its own derivative is that place.

Clifford\textquotesingle{}s {\itshape dual numbers}, of 1873, carry one derivative. Fike and Alonso added a second unit in 2011 and named the result a {\itshape hyper-\/dual} number, the prefix marking the several units as it does for the hypercomplex numbers built on more than one imaginary unit. {\bfseries{FLUXION}} takes $n$ units rather than two, which is what {\itshape generalized} names here. They form an algebra, and each of its properties has a name in the library.\hypertarget{flx_algebra_flx_one_unit}{}\doxysubsubsection{\texorpdfstring{One unit}{One unit}}\label{flx_algebra_flx_one_unit}
Adjoin to the reals a symbol $\varepsilon$ with $\varepsilon \neq 0$ and $\varepsilon^2 = 0$. An element is a pair $a + b\varepsilon$, and products close on that form, since the $\varepsilon^2$ term vanishes:\+

\[ (a + b\varepsilon)(c + d\varepsilon) = ac + (ad + bc)\,\varepsilon. \]

The coefficient of $\varepsilon$ obeys the product rule of \doxysectlink{flx_derivation_flx_rules}{Rules of computation}{1}, and for a function built from the arithmetic operations and the usual elementary functions,

\[ f(a + \varepsilon) = f(a) + f\textnormal{\textquotesingle}(a)\,\varepsilon. \]

This is the complex step made algebraic, with $\varepsilon^2 = 0$ in place of $i^2 = -1$. No $h$ has to be chosen and nothing cancels, and the coefficient of $\varepsilon$ is the derivative to the last bit the representation holds. In the library such a number is a type carrying its order:\+

\DoxyCodeLine{\doxymbox{\hyperlink{structflx_1_1hyperdual}{flx::hyperdual<double,1>}}\ z\{2.5,\ 1.0\};\ \ \ \textcolor{comment}{//\ 2.5\ +\ e1}}

\end{DoxyCode}
\hypertarget{flx_algebra_flx_n_units}{}\doxysubsubsection{\texorpdfstring{Several units}{Several units}}\label{flx_algebra_flx_n_units}
A second unit brings $\varepsilon_2$, and with it the product $\varepsilon_1\varepsilon_2$, which does not vanish since the two units are distinct. That component is where the second derivative lands. Let $\varepsilon_1, \dots, \varepsilon_n$ commute with each other and with the reals, and let each square to zero. The algebra they generate is

\[ \mathcal{H}_n = \mathbb{R}[\varepsilon_1,\dots,\varepsilon_n] \big/
    \left(\varepsilon_i\varepsilon_j - \varepsilon_j\varepsilon_i,\ \varepsilon_i^2\right), \]

a Weil algebra, the $n$-\/fold tensor power of $\mathbb{R}[\varepsilon]/(\varepsilon^2)$. A product of distinct units is not zero, and any product in which a unit appears twice is. The surviving products are therefore indexed by the subsets of $\{1,\dots,n\}$. Writing $\varepsilon_S = \prod_{i \in S} \varepsilon_i$, the basis is $(\varepsilon_S)_{S \subseteq \{1,\dots,n\}}$, the dimension is $2^n$, and the product of two basis elements is

\[ \varepsilon_S\,\varepsilon_T =
    \begin{cases} \varepsilon_{S \cup T} & \text{if } S \cap T = \emptyset, \\
                  0 & \text{otherwise.} \end{cases} \]

{\bfseries{FLUXION}} calls $n$ the {\bfseries{order}} and carries it in the type. The order is bounded, each one doubling the number of components stored:\+

Four is where {\bfseries{FLUXION}} stops. A value of order 4 holds sixteen components, every operation of the arithmetic works on all of them, and several of them answer the same derivative (see \doxysectlink{flx_seeding_flx_landing}{Reading a result}{1}).\hypertarget{flx_algebra_flx_components}{}\doxysubsubsection{\texorpdfstring{Component indexing}{Component indexing}}\label{flx_algebra_flx_components}
An element carries one coefficient per subset of the units, and is the sum of them:\+

\[ z = \sum_{S \subseteq \{1,\dots,n\}} z_S\,\varepsilon_S
      = z_\emptyset + z_{\{1\}}\varepsilon_1 + \dots + z_{\{1,\dots,n\}}\varepsilon_1\cdots
        \varepsilon_n. \]

The empty subset multiplies no unit, so $z_\emptyset$ is the ordinary number the element is built around, and {\bfseries{FLUXION}} calls it the {\bfseries{value}}. The other $2^n - 1$ coefficients form the {\bfseries{nilpotent part}}.

Each coefficient is a component of the stored value, and its index says which units it belongs to, one bit per unit:\+ bit $i$ set means the component carries $\varepsilon_{i+1}$. Index zero holds the value, and the indices that are powers of two hold the coefficients of the single units.

\hypertarget{flx_algebra_flx_constants}{}\doxysubsubsection{\texorpdfstring{Constants and variables}{Constants and variables}}\label{flx_algebra_flx_constants}
A value carrying no nilpotent part is a constant:\+ differentiating anything against it returns zero. A value carrying a one in front of every unit is a variable, which is what makes derivatives flow from it.

\begin{DoxyNote}{Note}
Completing by zeros would state that the missing derivatives vanish, which is an assertion about the function rather than a convention about storage.
\end{DoxyNote}
\hypertarget{flx_algebra_flx_arithmetic}{}\doxysubsubsection{\texorpdfstring{Sum, product, and inverse}{Sum, product, and inverse}}\label{flx_algebra_flx_arithmetic}
$\mathcal{H}_n$ is commutative and associative at every order, so an expression means what it is written to mean at order 4 as much as at order 1, and no parenthesis has to be watched. What grows is the size, doubling with each order, and every operation works on all of the components.

It is not a division algebra. Every element whose value is zero is nilpotent, hence a zero divisor. An element is invertible exactly when its value is, and the inverse is then a finite sum, the nilpotent part $N$ satisfying $N^{n+1} = 0$:\+

\[ \frac{1}{a + N} = \frac{1}{a}\sum_{k=0}^{n} \left(\frac{-N}{a}\right)^{k}. \]

Every arithmetic operator and every elementary function applies to a hyperdual and returns one, its components being those the algebra prescribes:\+

\hypertarget{flx_algebra_flx_order_relation}{}\doxysubsubsection{\texorpdfstring{No order relation}{No order relation}}\label{flx_algebra_flx_order_relation}
An ordered ring has no nilpotent element other than zero:\+ were $\varepsilon > 0$, squaring would give $0 > 0$. No comparison of two hyperduals can therefore extend the comparison of the reals, and the library compares values:\+

\end{DoxyCode}


Reading a derivative is done by component, by name or by index, and never by comparison.\hypertarget{flx_algebra_flx_subalgebra}{}\doxysubsubsection{\texorpdfstring{Lower orders as prefixes}{Lower orders as prefixes}}\label{flx_algebra_flx_subalgebra}
The units $\varepsilon_1, \dots, \varepsilon_k$ generate a subalgebra of $\mathcal{H}_n$ for $k \le n$. The binary layout of the indices places it first:\+ the first $2^k$ components are exactly the subsets of the first $k$ units, so reading an order $k$ out of an order $n$ is taking a prefix, component for component.
