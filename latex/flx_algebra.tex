\doxysubsection{Hyperdual Algebra }
\hypertarget{flx_algebra}{}\label{flx_algebra}\index{Hyperdual Algebra@{Hyperdual Algebra}}
\label{flx_algebra_md__2____w_2fluxion_2fluxion_2doc_2algebra}%
\Hypertarget{flx_algebra_md__2____w_2fluxion_2fluxion_2doc_2algebra}%


Forward mode needs a type holding a value together with the requested derivatives, and an arithmetic that updates both at every operation. Clifford\textquotesingle{}s {\itshape dual numbers} (1873) carry one derivative. Fike and Alonso added a second unit in 2011 and named the result a {\itshape hyper-\/dual} number, the prefix marking the presence of several units, as it does for hypercomplex numbers built on more than one imaginary unit. {\bfseries{FLUXION}} takes $n$ units in place of two; {\itshape generalized} refers to that extension. The units generate an algebra; the library names its order and, within an element, the value and the nilpotent part.\hypertarget{flx_algebra_flx_one_unit}{}\doxysubsubsection{\texorpdfstring{Dual numbers}{Dual numbers}}\label{flx_algebra_flx_one_unit}
Adjoin to the reals a symbol $\varepsilon$ with $\varepsilon \neq 0$ and $\varepsilon^2 = 0$. That symbol is the {\bfseries{dual unit}}, as $i$ is the imaginary unit of the complex numbers. An element is a pair $a + b\varepsilon$, and the product of two such pairs has the same form, since the $\varepsilon^2$ term vanishes:\+

\[ (a + b\varepsilon)(c + d\varepsilon) = ac + (ad + bc)\,\varepsilon. \]

The coefficient of $\varepsilon$ obeys the product rule of \doxysectlink{flx_derivation_flx_rules}{Rules of computation}{1}, and for a function built from the arithmetic operations and the usual elementary functions,

\[ f(a + \varepsilon) = f(a) + f\textnormal{\textquotesingle}(a)\,\varepsilon. \]

The construction is that of the complex step, with $\varepsilon^2 = 0$ in place of $i^2 = -1$. No $h$ has to be chosen, and nothing cancels:\+ the coefficient of $\varepsilon$ is the derivative, rounded as the value is. In the library, such a number is an instance of a type carrying its order:\+

\DoxyCodeLine{\doxymbox{\hyperlink{structflx_1_1hyperdual}{flx::hyperdual<double,1>}}\ z\{2.5,\ 1.0\};\ \ \ \textcolor{comment}{//\ 2.5\ +\ e1}}

\end{DoxyCode}
\hypertarget{flx_algebra_flx_n_units}{}\doxysubsubsection{\texorpdfstring{Hyperdual numbers}{Hyperdual numbers}}\label{flx_algebra_flx_n_units}
A second unit $\varepsilon_2$ adds the product $\varepsilon_1\varepsilon_2$, which does not vanish since the two units are distinct. Its coefficient holds the second derivative. Let $\varepsilon_1, \dots, \varepsilon_n$ commute with each other and with the reals, and let each square to zero. The algebra they generate is

\[ \mathcal{H}_n = \mathbb{R}[\varepsilon_1,\dots,\varepsilon_n] \big/
    \left(\varepsilon_1^2,\dots,\varepsilon_n^2\right), \]

a Weil algebra, the $n$-\/fold tensor power of $\mathbb{R}[\varepsilon]/(\varepsilon^2)$. A product of distinct units is not zero, and any product in which a unit appears twice is zero. The nonzero products are therefore indexed by the subsets of $\{1,\dots,n\}$. With $\varepsilon_S = \prod_{i \in S} \varepsilon_i$, the basis is $(\varepsilon_S)_{S \subseteq \{1,\dots,n\}}$, the dimension is $2^n$, and the product of two basis elements is

\[ \varepsilon_S\,\varepsilon_T =
    \begin{cases} \varepsilon_{S \cup T} & \text{if } S \cap T = \emptyset, \\
                  0 & \text{otherwise.} \end{cases} \]

{\bfseries{FLUXION}} calls $n$ the {\bfseries{order}} and carries it in the type. The order is bounded, each increment of it doubling the number of components stored:\+

$\mathcal{H}_n$ is defined for every $n$, and the bound is the library\textquotesingle{}s:\+ the number of components doubles at each order, every operation works on all of the components, and past order 4 the compile times become impractical.\hypertarget{flx_algebra_flx_components}{}\doxysubsubsection{\texorpdfstring{Component indexing}{Component indexing}}\label{flx_algebra_flx_components}
An element has one coefficient per subset of the units, and is the sum of the corresponding terms:\+

\[ z = \sum_{S \subseteq \{1,\dots,n\}} z_S\,\varepsilon_S
      = z_\emptyset + z_{\{1\}}\varepsilon_1 + \dots + z_{\{1,\dots,n\}}\varepsilon_1\cdots
        \varepsilon_n. \]

The empty subset contributes no unit, so $z_\emptyset$ is the real part of the element, and {\bfseries{FLUXION}} calls it the {\bfseries{value}}. The other $2^n - 1$ coefficients form the {\bfseries{nilpotent part}}.

Each coefficient is a component of the stored element, and its index encodes the units it carries, one bit per unit:\+ a set bit $i$ indicates that the component carries $\varepsilon_{i+1}$. Index zero holds the value, and the indices that are powers of two hold the coefficients of the single units.

\hypertarget{flx_algebra_flx_constants}{}\doxysubsubsection{\texorpdfstring{Constants and variables}{Constants and variables}}\label{flx_algebra_flx_constants}
An element carrying no nilpotent part is a constant:\+ differentiating anything with respect to it returns zero. An element carrying a coefficient of one on every unit is a variable:\+ derivatives are taken with respect to it.

Building a variable is called seeding, and \doxylink{flx_seeding}{Seeding and Reading} gives the forms that seed the arguments of a call.

A hyperdual is built from a complete list of components. A single value, a value with {\ttfamily \doxylink{group__types_ga02fcc261be278ce3a28010fe7f07b998}{flx::\+var}}, the full list of components, and a tuple of the same size are the only ways to build one; a partial list is refused:\+

\hypertarget{flx_algebra_flx_arithmetic}{}\doxysubsubsection{\texorpdfstring{Sum, product, and inverse}{Sum, product, and inverse}}\label{flx_algebra_flx_arithmetic}
$\mathcal{H}_n$ is commutative and associative at every order, so an expression has the same value in exact arithmetic whatever the sequence of its operations; in floating point, as on the reals, its rounding still depends on that sequence.

$\mathcal{H}_n$ is not a division algebra. Every element whose value is zero is nilpotent, hence a zero divisor. An element is invertible exactly when its value is, and the inverse is then a finite sum, the nilpotent part $N$ satisfying $N^{n+1} = 0$. For a nonzero value $a$:\+

\[ \frac{1}{a + N} = \frac{1}{a}\sum_{k=0}^{n} \left(\frac{-N}{a}\right)^{k}. \]

Every arithmetic operator and every elementary function applies to a hyperdual and returns one, its components being those the algebra prescribes:\+

\hypertarget{flx_algebra_flx_subalgebra}{}\doxysubsubsection{\texorpdfstring{Lower orders as prefixes}{Lower orders as prefixes}}\label{flx_algebra_flx_subalgebra}
The units $\varepsilon_1, \dots, \varepsilon_k$ generate a subalgebra of $\mathcal{H}_n$ for $k \le n$, and the binary layout of the indices stores its components at the lowest indices:\+

\[ S \subseteq \{1,\dots,k\} \iff \mathrm{index}(\varepsilon_S) < 2^k. \]

Reading an element of order $k$ out of one of order $n$ therefore takes a prefix of the components.
