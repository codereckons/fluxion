\hypertarget{flx_glossary_flx_gl_float}{}\doxysubsubsection{\texorpdfstring{Floating-\/point arithmetic}{Floating-\/point arithmetic}}\label{flx_glossary_flx_gl_float}
\hypertarget{flx_glossary_autotoc_md0}{}\doxysubsubsubsection{\texorpdfstring{Unit roundoff}{Unit roundoff}}\label{flx_glossary_autotoc_md0}
The largest relative error a single correctly rounded floating-\/point operation can make, written $u$. It is $2^{-24}$ for {\ttfamily float} and $2^{-53}$ for {\ttfamily double}, and it sets the number of digits any result can hold.\hypertarget{flx_glossary_autotoc_md1}{}\doxysubsubsubsection{\texorpdfstring{Cancellation}{Cancellation}}\label{flx_glossary_autotoc_md1}
The loss of significant digits when two nearby values are subtracted. The difference is computed exactly, and the digits the two operands had in common disappear from it, so the error they already carried becomes the leading part of the result. It limits a difference quotient as $h$ shrinks.\hypertarget{flx_glossary_autotoc_md2}{}\doxysubsubsubsection{\texorpdfstring{Truncation error}{Truncation error}}\label{flx_glossary_autotoc_md2}
The part of a formula that is dropped. A forward difference omits a term of order $h$, which is its truncation error, and it shrinks with $h$ while the cancellation grows.\hypertarget{flx_glossary_flx_gl_algebra}{}\doxysubsubsection{\texorpdfstring{Algebra}{Algebra}}\label{flx_glossary_flx_gl_algebra}
\hypertarget{flx_glossary_autotoc_md3}{}\doxysubsubsubsection{\texorpdfstring{Unit}{Unit}}\label{flx_glossary_autotoc_md3}
A symbol $\varepsilon_i$ adjoined to the reals with $\varepsilon_i \neq 0$ and $\varepsilon_i^2 = 0$, called the dual unit in the literature, defined in \doxysectlink{flx_algebra_flx_one_unit}{Dual numbers}{1}. An element of order $n$ carries $n$ of them, and each of its components is indexed by the set of units that component carries. The unit roundoff of \doxysectlink{flx_glossary_flx_gl_float}{Floating-\/point arithmetic}{1} is an unrelated term.\hypertarget{flx_glossary_autotoc_md4}{}\doxysubsubsubsection{\texorpdfstring{Nilpotent}{Nilpotent}}\label{flx_glossary_autotoc_md4}
An element some power of which is zero. The units of \doxylink{flx_algebra}{Hyperdual Algebra} satisfy $\varepsilon_i^2 = 0$, and any element with no real part satisfies $N^{n+1} = 0$ at order $n$.\hypertarget{flx_glossary_autotoc_md5}{}\doxysubsubsubsection{\texorpdfstring{Order}{Order}}\label{flx_glossary_autotoc_md5}
In {\bfseries{FLUXION}}, the number of nilpotent units an element carries, written {\ttfamily Ord} in the types. An element of order $n$ holds $2^n$ components and derivatives up to the $n$-\/th.\hypertarget{flx_glossary_flx_gl_simd}{}\doxysubsubsection{\texorpdfstring{SIMD registers}{SIMD registers}}\label{flx_glossary_flx_gl_simd}
\hypertarget{flx_glossary_autotoc_md6}{}\doxysubsubsubsection{\texorpdfstring{Width}{Width}}\label{flx_glossary_autotoc_md6}
EVE\textquotesingle{}s term for the number of lanes of a SIMD register, read by {\ttfamily eve::\+width\+\_\+v}. It counts the points evaluated together, while the order counts the derivatives one point carries.\hypertarget{flx_glossary_autotoc_md7}{}\doxysubsubsubsection{\texorpdfstring{Structure of arrays}{Structure of arrays}}\label{flx_glossary_autotoc_md7}
A layout storing one array per field rather than one record per element. {\ttfamily eve::\+wide} of a hyperdual holds one register per component, so an operation on a component is one SIMD instruction.\hypertarget{flx_glossary_flx_gl_ad}{}\doxysubsubsection{\texorpdfstring{Automatic differentiation}{Automatic differentiation}}\label{flx_glossary_flx_gl_ad}
\hypertarget{flx_glossary_autotoc_md8}{}\doxysubsubsubsection{\texorpdfstring{Seeding}{Seeding}}\label{flx_glossary_autotoc_md8}
Assigning nilpotent units to an argument, so that the derivatives with respect to it are indexed by those units. Griewank and Walther\textquotesingle{}s term for the same operation in forward mode. In {\bfseries{FLUXION}} it is {\ttfamily \doxylink{group__types_ga487d2e600f4745c7eae18474d9641300_ga487d2e600f4745c7eae18474d9641300}{flx::\+variable}}, {\ttfamily \doxylink{group__types_gad882c0e62192532ad693d74ebdeb394d_gad882c0e62192532ad693d74ebdeb394d}{flx::\+variables}}, and the {\ttfamily \doxylink{group__types_ga02fcc261be278ce3a28010fe7f07b998}{flx::\+var}} constructor (see \doxysectlink{flx_seeding_flx_assignment}{Differentiation list}{1}).\hypertarget{flx_glossary_autotoc_md9}{}\doxysubsubsubsection{\texorpdfstring{Forward mode}{Forward mode}}\label{flx_glossary_autotoc_md9}
Automatic differentiation carrying the derivatives alongside the value, in the sequence the program computes. One pass returns the value and the derivatives with respect to the seeded arguments.\hypertarget{flx_glossary_autotoc_md10}{}\doxysubsubsubsection{\texorpdfstring{Reverse mode}{Reverse mode}}\label{flx_glossary_autotoc_md10}
Automatic differentiation recording the operations of an evaluation, then traversing the record backward to accumulate derivatives. One forward pass, which stores the record, and one backward pass return the gradient with respect to every input.
