Background  {#background}
=========================

What **FLUXION** computes is a derivative, and it computes it by arithmetic rather than by
approximation. These pages say what that arithmetic is, what a value of the library carries, and
what the alternatives cost.

  + @subpage math_background, the algebra the library is built on;
  + @subpage derivatives_background, how a derivative is asked for and read back;
  + @subpage alternatives_background, what the other ways of differentiating a program cost.
